# Merchandise Online Store "Chindoren"

Website toko online sederhana berbasis Flask untuk menampilkan katalog produk, menambahkan item ke keranjang, dan melanjutkan proses checkout.

## Fitur inti

- Menampilkan daftar produk dan kategori.
- Menyediakan pencarian, filter, dan pengurutan produk.
- Memiliki keranjang belanja berbasis sesi.
- Mendukung halaman detail produk dan produk terkait.
- Menyediakan form checkout sederhana beserta halaman sukses setelah pemesanan.

## Cara menjalankan

```bash
pip install flask
python3 app.py
```

Buka browser ke:

```text
http://127.0.0.1:5000
```
