# Project Chindoren

Sistem kasir CLI dan katalog merchandise untuk tugas akhir Mata Kuliah Bahasa Pemrograman.

## Deskripsi

Aplikasi sederhana berbasis Python yang menyediakan katalog produk, keranjang belanja, dan proses checkout dengan perhitungan diskon otomatis.

## Fitur

- Menampilkan katalog merchandise Chindoren
- Menambahkan produk ke keranjang
- Melihat isi keranjang belanja
- Menghitung total pembayaran dan diskon
- Mengosongkan keranjang setelah checkout

## Struktur Projek

- `app.py` - aplikasi kasir Python
- `main.html` - halaman web pendukung (jika diperlukan)
- `main.css` - stylesheet pendukung untuk halaman web
- `README.md` - dokumentasi proyek

## Cara Menjalankan

1. Pastikan Python terpasang di sistem.
2. Buka terminal di folder proyek.
3. Jalankan:

```bash
python app.py
```

4. Ikuti instruksi menu untuk mengelola katalog dan keranjang belanja.

## Catatan

- Aplikasi ini berjalan di terminal/CLI.
- Format harga menggunakan format Indonesia (Rp).
- Stok produk berkurang saat item ditambahkan ke keranjang.

## Lisensi

Tidak ada lisensi khusus; gunakan sesuai kebutuhan tugas dan pembelajaran.
